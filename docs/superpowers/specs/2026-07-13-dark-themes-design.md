# Selectable dark themes

**Date:** 2026-07-13
**Status:** Approved (follow-up to 2026-07-13-purple-theme-design.md)

## Goal

Make the palette selectable. Ship five dark themes — Purple (default),
Emerald, Ocean, Rose, Amber — chosen from the command palette, persisted in
localStorage. Light mode is out of scope for now.

## Design

### 1. Finish tokenization

All theme-hued (purple-cast) color literals in `styles.css`,
`linear-section.css`, `notes-section.css`, `session-tree.css`, and
`tmux-create.css` are folded into a 17-token scale on `:root`. Literals map
to the nearest token by HSL lightness band (all share hue ≈253, so this is a
consolidation, not a redesign):

surface-deep, bg, surface, surface-raised, surface-soft, surface-hover,
border, border-mid (new), border-strong, text-faint (new), text-dim (new),
muted-dim (repointed dimmer than muted), muted, text-soft, text, accent,
accent-ink.

Translucent purple rgba() literals become
`color-mix(in srgb, var(--token) N%, transparent)`. Accent glows
(`rgba(157, 133, 244, α)` / `rgba(185, 163, 255, α)`) become
`color-mix(in srgb, var(--accent) N%, transparent)`.

Not tokenized (constant across themes): semantic status colors (`--green`
done/OpenCode, `--cyan`, `--amber`, `--red`, `--purple` Claude badge), error
and warning tints, Rosé Pine accent constants in the notes/tmux-create
sections (`#eb6f92`, `#f6c177`, `#9ccfd8`, `#3e8fb0`), pure blacks/whites,
`--terminal-bg`, and the xterm ANSI theme.

### 2. Theme definitions

`:root[data-theme="<name>"]` blocks in `styles.css`, each overriding the 17
tokens. Values are generated by rotating the default purple tokens to the
theme hue with saturation/lightness preserved (HSL): emerald 152, ocean 205,
rose 345, amber 40. Purple is the `:root` default (no attribute).

### 3. Runtime

- `src/theme.ts`: `THEMES`, `storedTheme()` (localStorage
  `commando-theme`, falls back to purple on garbage), `applyTheme(name)`
  (sets `data-theme` on `<html>`, persists, updates the `theme-color` meta
  to the theme's bg).
- `src/main.tsx`: apply the stored theme before first render.
- `src/App.tsx`: five palette actions `Theme: <Label>` (kind `action`);
  the active one is marked in its detail line.

### 4. Testing

Unit tests for `theme.ts` (apply/persist/fallback/meta). Visual pass per
theme via the Playwright recipe in `.claude/skills/verify/SKILL.md`.
